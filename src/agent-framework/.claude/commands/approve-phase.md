# /approve-phase コマンド

指定したフェーズをレビュー完了として承認し、次フェーズへの進行を許可します。

## 使用方法

```
/approve-phase N
```

## 引数

- `N`: フェーズ番号（1-7）

## フェーズ定義

| Phase | 成果物 | 承認基準 |
|-------|--------|---------|
| 1 | ヒアリング記録 | 要件が明確化されている |
| 2 | 要求定義書 | WHAT（何を実現するか）が明確 |
| 3 | 設計書 | HOW（どう実現するか）が明確 |
| 4 | WBS | タスク分解・役割分担が明確 |
| 5 | 成果物 | 実装完了・動作確認済み |
| 6 | 完了報告 | 振り返りが完了 |
| 7 | Issue管理 | 今後の課題が整理されている |

---

## 実行内容

### ステップ1: 引数の確認

引数からフェーズ番号を取得:
- 1-7 のいずれかであること
- 不正な値の場合はエラーメッセージを表示

### ステップ2: 成果物の確認

承認対象フェーズの成果物が存在するか確認。

### ステップ3: レビュー確認

ユーザーに確認:

```markdown
## Phase N 承認確認

**成果物**: [ファイルパス]

以下を確認してください:
- [ ] 内容をレビューしましたか？
- [ ] 承認基準を満たしていますか？

承認してよろしいですか？ (y/n)
```

### ステップ4: 承認ファイル作成

承認が確認されたら、タイムスタンプ付きで承認ファイルを作成:

```bash
mkdir -p .claude/approvals
echo "YYYY-MM-DD HH:MM:SS - Approved" > .claude/approvals/phase-N-approved.txt
```

### ステップ5: 完了報告

```markdown
## Phase N 承認完了

**承認日時**: YYYY-MM-DD HH:MM:SS
**承認ファイル**: .claude/approvals/phase-N-approved.txt

### 次のステップ
[次に実行可能なフェーズの案内]
```

---

## 重要な注意事項

1. **順序遵守**: Phase 1 → 2 → 3 → ... の順で承認する必要があります
2. **成果物必須**: 成果物がない状態では承認できません
3. **人間の確認**: 承認はユーザーの明示的な同意が必要です
4. **取り消し**: 承認ファイルを削除すれば承認を取り消せます
