# フェーズ承認コマンド

指定したフェーズをレビュー完了として承認し、次フェーズへの進行を許可します。

---

## 使用方法

```
/approve-phase 1   # Phase 1（要求定義書）を承認
/approve-phase 2   # Phase 2（設計書）を承認
/approve-phase 3   # Phase 3（WBS）を承認
/approve-phase 4   # Phase 4（成果物）を承認 → 完了
```

---

## フェーズ定義

| Phase | 成果物 | 承認基準 |
|-------|--------|---------|
| 1 | 要求定義書 | WHAT（何を実現するか）が明確 |
| 2 | 設計書 | HOW（どう実現するか）が明確 |
| 3 | WBS | タスク分解・工数・役割分担が明確 |
| 4 | 成果物 | 実装完了・動作確認済み |

---

## 指示内容

あなた（Claude Code）は、以下の手順でフェーズを承認してください:

### ステップ1: 引数の確認

引数 `$ARGUMENTS` からフェーズ番号を取得:
- 1, 2, 3, 4 のいずれかであること
- 不正な値の場合はエラーメッセージを表示

### ステップ2: 成果物の確認

承認対象フェーズの成果物が存在するか確認:

| Phase | 確認対象ファイル |
|-------|----------------|
| 1 | `documents/*/01_要求定義書.md` |
| 2 | `documents/*/02_設計書.md` |
| 3 | `documents/*/03_WBS.md` |
| 4 | `src/` 配下に成果物が存在 |

### ステップ3: レビュー確認

ユーザーに確認:

```markdown
## Phase [N] 承認確認

**成果物**: [ファイルパス]

以下を確認してください:
- [ ] 内容をレビューしましたか？
- [ ] 承認基準を満たしていますか？

承認してよろしいですか？ (y/n)
```

### ステップ4: 承認ファイル作成

承認が確認されたら、タイムスタンプ付きで承認ファイルを作成:

```bash
mkdir -p .claude/approvals
echo "$(date +%Y-%m-%d\ %H:%M:%S) - Approved by user" > .claude/approvals/phase-[N]-approved.txt
```

### ステップ5: 完了報告

```markdown
## Phase [N] 承認完了

**承認日時**: YYYY-MM-DD HH:MM:SS
**承認ファイル**: .claude/approvals/phase-[N]-approved.txt

### 現在の承認状況
- Phase 1: [承認済み / 未承認]
- Phase 2: [承認済み / 未承認]
- Phase 3: [承認済み / 未承認]
- Phase 4: [承認済み / 未承認]

### 次のステップ
[次に実行可能なフェーズの案内]
```

---

## 重要な注意事項

1. **順序遵守**: Phase 1 → 2 → 3 → 4 の順で承認する必要があります
2. **成果物必須**: 成果物がない状態では承認できません
3. **人間の確認**: 承認はユーザーの明示的な同意が必要です
4. **取り消し**: 承認ファイルを削除すれば承認を取り消せます

---
