# business/

業務ルールと行動指針を格納するフォルダです。

## 特徴

- **起動時に必ず読み込む**（最優先）
- エージェントの行動規範を定義
- 組織のポリシーを反映

## 例

```markdown
# 承認ルール

## 金額別承認権限

| 金額 | 承認者 |
|------|--------|
| 〜10万円 | 課長 |
| 〜100万円 | 部長 |
| 100万円〜 | 役員 |
```

## ファイル命名規則

```
[カテゴリ]_[内容].md

例:
- approval_rules.md（承認ルール）
- naming_conventions.md（命名規約）
- workflow_policies.md（ワークフロー方針）
```
