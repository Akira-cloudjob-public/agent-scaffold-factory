# people/

関係者情報と組織構造を格納するフォルダです。

## 特徴

- 必要時に参照
- ステークホルダーの情報を管理
- 連絡先や役割を記録

## 例

```markdown
# プロジェクトメンバー

## コアメンバー

| 役割 | 名前 | 連絡先 |
|------|------|--------|
| プロジェクトオーナー | 田中 | tanaka@example.com |
| 技術リード | 鈴木 | suzuki@example.com |

## レビュー体制

| 成果物 | 一次レビュー | 最終承認 |
|--------|-------------|---------|
| 要求定義書 | 鈴木 | 田中 |
| 設計書 | 鈴木 | 田中 |
```

## ファイル命名規則

```
[組織/プロジェクト]_members.md

例:
- project_members.md（プロジェクトメンバー）
- stakeholders.md（ステークホルダー）
- org_structure.md（組織構造）
```
